# THALVO MarineOS — Piri Reis Osmanlı Haritası Edisyonu

Aynı gold-on-black tonlarda **Piri Reis / Osmanlı portolan haritası** temalı ön–arka polo seti.

## Tema

- 16. yy Osmanlı deniz haritası (portolan) estetiği
- Rüzgar gülü / compass rose, rhumb çizgileri, kıyı hatları, dönem gemileri
- THALVO crest (deniz feneri / dümen) harita madalyonu içinde
- Renk: champagne / sand gold + cyan MarineOS · siyah kumaş
